# File Integrity Checker

## Project Purpose

This project checks whether a file has been modified by comparing its SHA-256 hash with the original hash.

## Skills Practiced

- Python file handling
- SHA-256 hashing
- File integrity checking
- Tampering detection
- Conditional statements

## Technologies Used

- Python 3
- hashlib

## Files

- file_checker.py
- security_file.txt
