# Network Information Tool

## Project Purpose

This project collects basic network information using Python.

## Features

- Get system hostname
- Get local IP address
- Resolve a domain name to an IP address
- Perform reverse DNS lookup

## Technologies Used

- Python
- Socket module

## Example Output

```
Hostname: DESKTOP-MBK7L0G
Local IP: 192.168.56.1
Google IP: 142.250.200.174
Reverse DNS: pnfjra-aq-in-f14.1e100.net
```
