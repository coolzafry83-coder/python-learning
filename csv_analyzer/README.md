# CSV Salary Analyzer

A Python project that reads employee salary data from a CSV file and performs basic salary analysis.

## Features

- Calculate total salary
- Calculate average salary
- Find highest salary
- Find lowest salary
- Find highest-paid employee
- Find lowest-paid employee
- Count total employees

## Example Output

Total salary: 210000
Average salary: 52500.0
Highest salary: 60000
Lowest salary: 40000
Highest paid employee: Ahmed
Salary: 60000
Lowest paid employee: Usman
Salary: 40000
Total employees: 4
