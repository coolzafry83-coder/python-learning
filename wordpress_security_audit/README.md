# WordPress Security Audit

## Project Overview

A security audit of a local WordPress lab to identify common security risks and document recommended improvements.

## Environment

* Platform: WordPress
* Server: XAMPP / Apache
* Database: MariaDB
* Scope: Local lab only

## Audit Checklist

* [x] WordPress dashboard access verified
* [x] WordPress version and update status checked
* [ ] User account security reviewed
* [ ] Plugin and theme security reviewed
* [ ] Security configuration reviewed
* [ ] Findings and remediation documented
